# Проект Telegram Mini App магазина новых вещей

Версия 1.2 · 2 ноября 2026.

Откройте Secondhand_Telegram_Project.html: полный автономный проект с десятью мобильными макетами и ссылками на источники. Интернет для чтения не требуется.

Secondhand_Telegram_Project.md — та же спецификация для разработчика.
DESIGN_Airbnb.md — исходный дизайн-референс без изменений.
Папка screens — 10 PNG и редактируемых SVG, 390×844 px.
Secondhand_Mobile_Screens.png — обзор шести покупательских экранов.

Ассортимент: только новые вещи, включая детскую одежду, сумки и аксессуары. Нет блоков состояния/дефектов. Бронь бесплатная, без количественных лимитов, продления и санкций за неявки. Телефон обязателен при оформлении. Срок — до закрытия следующего календарного дня после готовности, с переносом закрытого дня. Почта только в отделения: покупатель оплачивает товары и все расходы отправки; владелец отправляет до конца следующего рабочего дня после проверки. Поддержка — обычный Telegram-аккаунт магазина.

IT-бюджет до 50 BYN/месяц с обязательными дополнениями, домен отдельно. Кандидат хостинга не является оплаченным тарифом: конечный счёт ещё нужно проверить. Онлайн-оплаты, финансового модуля, API почт и настраиваемых резервных копий сейчас нет.

O01–O14 фиксируют решения. D01–D18 охватывают разработку, T01–T37 — будущая приёмка, а не результаты тестирования существующего приложения. На этом этапе код и развёртывание не выполнялись.

Макеты содержат учебные сведения и внешние фото-референсы. Перед запуском нужны собственные фотографии ассортимента. Правовые требования пересмотрены для новых товаров; полные действующие редакции ряда актов не удалось проверить. Раздел 10 и реестр L1–L4 явно перечисляют необходимые подтверждения перед запуском. Условия почтовых договоров также сверяются для конкретного магазина.
