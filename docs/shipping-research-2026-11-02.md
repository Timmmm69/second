# Европочта: проверенные условия и границы запуска

Проверено 2 ноября 2026 по официальному сайту оператора. Web search несколько раз не смог прочитать страницы; затем HTML официальных страниц получен напрямую, без входа и передачи данных продавца.

| Вопрос | Подтверждение | Решение для магазина |
|---|---|---|
| Юридическое лицо | [Начало сотрудничества](https://evropochta.by/info/faq/sent_entity.html): договор, анкета/документы, проверка и личный кабинет | Не снимать серверное требование договора без фактического основания |
| Документы для ИП | [Документы](https://evropochta.by/info/documents_2/) содержат отдельные образцы для юрлица и ИП | Фактический статус продавца ещё неизвестен; определить применимый договор до включения |
| Доставка/упаковка/перевод за счёт получателя | [Сервис](https://evropochta.by/info/faq/payer_recipient.html) доступен юрлицам и ИП с договором; плательщика выбирают до приёмки | Схема соответствует запросу владельца при выполнении условий оператора; договор пока отсутствует |
| Наложенный платёж | [Описание](https://evropochta.by/info/faq/cod.html): получение денег с адресата и перечисление отправителю; для юрлица сроки определяются договором | Онлайн-платёж в Mini App не добавляется; реальная схема ожидает договора |
| Расходы/комиссии | [Тарифы для юрлиц](https://evropochta.by/services/tariffs_ur/) датированы 01.10.2026; базовая пересылка и допуслуги указаны без НДС 20%, упаковка отдельно с НДС | Сумму считать по весу, пунктам, объявленной ценности и договору. В приложении нет выдуманной фиксированной цены |
| Расхождение источников | FAQ о наложенном платеже указывает 1,5% без НДС, датированная таблица для юрлиц — 1,8% без НДС | Не закреплять ставку в коде/публичных условиях; сверить с оператором для конкретного договора |
| Невостребованное отправление | [Возврат](https://evropochta.by/info/faq/parcel_return.html): возврат платный; неоплаченная пересылка по сервису за счёт получателя также выставляется отправителю | Не обещать, что все расходы при любом исходе понесёт покупатель; неизвестные условия согласовать до отправки |
| Упаковка | [Требования](https://evropochta.by/info/packing_requirements/): упаковка по характеру вложения, защищает содержимое и исключает доступ без нарушения | Сотрудник проверяет упаковку вручную, стоимость не подставляется автоматически |

Вывод: подходящая корпоративная схема требует договора по опубликованной инструкции оператора. Оснований разрешить рабочую корпоративную отправку без договора не установлено. Сохранены серверные проверки, в новой рабочей базе обе почты выключены. Целевой старт после проверки — самовывоз + Европочта; Белпочта остаётся выключенной. Полный технический путь проверяется в изолированных тестах; ни кабинет, ни посылки, ни платежи не создавались.

Данные заявки: ФИО, телефон, населённый пункт, номер/название пункта и отдельный адрес пункта (`officeAddress`); индекс для Европочты необязателен. Старые снимки с единым полем `office` читаются без изменений. Новые заявки Европочты и изменение получателя требуют отдельный адрес. Данные шифруются на сервере; публичное демо не принимает их.
