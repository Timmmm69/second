# Кандидат размещения в пределах 50 BYN

Проверено 2 ноября 2026, без покупки или регистрации. Первичный источник — [Hostfly VPS](https://www.hostfly.by/tariffs/virtual-server/), дополнительно проверен действующий [конструктор](https://my.hostfly.by/index.php?m=hf_builder&p=vps&plan=1) в браузере.

| Параметр | Выбранная конфигурация |
|---|---|
| Тариф | Стандартный CloudVPS-1, без Managed |
| Ресурсы | 1 ядро, 2 ГБ RAM, 40 ГБ NVMe, 1 ТБ трафика |
| Локация | Минск; официальный сайт указывает белорусские ЦОД А1/BeCloud |
| ОС | Ubuntu 24.04 LTS, только ОС; Node/Docker устанавливаются отдельно |
| IPv4 | 1 адрес включён в тариф, подтверждено конструктором |
| Оплата | 1 месяц, **32,99 BYN/месяц** в итоговой конфигурации |
| Не выбраны | Платная панель, Managed, дополнительный IP/диск, BitNinja, снимки, S3 и прочие платные дополнения |
| Акционная цена | 29,69 BYN/месяц относится к оплате за год, её не используем для месячного бюджета |
| Домен отдельно | [.BY — 37 BYN за год регистрации](https://www.hostfly.by/domains/), продление оплачивается отдельно; выбранное имя ещё не проверялось |

Конструктор показывает 32,99 BYN за выбранный месяц с включённым IPv4 и без дополнений. Отдельной строки налога до корзины нет; итоговый счёт с применимыми налогами ещё не получен. Это кандидат, а не одобренный расход. Перед оплатой сверить окончательный счёт, владение учётной записью/доменом и отсутствие обязательных дополнений; совокупный месячный платёж должен остаться ≤50 BYN. Никакая подписка не оформлена.

Для примерно 20 вещей это разумная стартовая гипотеза: 20 × 6 фото × условные 3 МБ ≈360 МБ очищенных оригиналов плюс варианты. Фактические размеры измеряются после загрузки; нужна память для Sharp и свободный диск для БД/ОС/образов. Сборку лучше выполнять вне маломощного VPS; для приёмки замерить память/CPU/обработку фото и p95 на реальном тарифе. 40 ГБ не обещают вместимость многотысячного каталога без замера.

Резервные копии не подключены. У провайдера есть отдельные ежедневные снимки от 6,60 BYN/месяц (семь копий), но это только предложение для отдельного согласования. Ни опция, ни расписание не выбраны; восстановления потерянного диска сейчас не обещаем. Полный Compose/HTTPS на этом тарифе ещё не проверен: VPS не приобретён.
