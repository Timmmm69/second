# Internal integration contract 1.2
All API routes under /api, JSON camelCase except database columns. Root owns package, auth, catalog, settings, media, app registration. Domain owns migrations/001.sql + inventory.ts + orders.ts + calendar.ts + jobs.ts + worker.ts. Frontend owns client/** + index.html. Infra owns infra/**, scripts/{owner,seed,telegram}.ts, README, docs/{coverage,progress,launch,staff,verification}.md. No shared edits without messaging.

Root provides server/db.ts: export pool (pg.Pool), tx<T>((client:PoolClient)=>Promise<T>), query(text,params). server/errors.ts exports AppError(status,code,message,fields?) and assert(condition,status,code,message). server/types.ts Actor {id:string,telegramId:string,role:'BUYER'|'STAFF'|'OWNER'}. DB users(id uuid,telegram_id bigint,role text,display_name text, created_at), sessions, store_settings(id bool PK,value jsonb,version int). Domain defines full schema including these baseline tables. All UUID app-generated or gen_random_uuid. Root provides config. Contact snapshots AES-GCM via server/crypto.ts encrypt(value):string,decrypt(value):any. Never log recipient data.

Domain exports registerOrders(app:FastifyInstance) routes (Actor as req.actor via declaration), worker tick(pool) or tick() from jobs.ts. req.actor undefined for public, defined for guarded routes; root preHandler guards /me,/checkout,/orders,/operations staff and owner globally by path. Transactions idem persistent; item state writes only inventory.ts. DB item JSON attributes and measurements, media list separate. Frontend consumes:
GET /auth/me -> {user:{id,telegramId,role},dev:boolean}; POST /auth/telegram {initData}; POST /auth/dev {role:'BUYER'|'STAFF'|'OWNER'} LOCAL only, fixed ids per role.

GET /categories -> [{id,name,measurements:string[]}].
GET /catalog?q=&category=&brand=&color=&material=&season=&audience=&sizeSystem=&sizeLabel=&minPrice=&maxPrice=&minHeight=&maxHeight=&measurement=&minMeasure=&maxMeasure=&sort=new|price_asc|price_desc&cursor= -> {items:Item[],nextCursor}. GET /items/:id -> Item (public safe even unavailable; no staff fields).

Sensitive owner writes production require recent reauth + TOTP via header X-Owner-Code.
Errors {code,message,fieldErrors?,correlationId,conflicts?:[{itemId,reason}]}; 409 version includes latest via reload. Every route real PostgreSQL no memory persistence. No deployment, payment, backup integration. Test seed must reject NODE_ENV production and require ALLOW_DEV_SEED=1.
